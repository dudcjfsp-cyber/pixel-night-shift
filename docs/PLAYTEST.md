## 공통 Product V2 E2E

다음 경로를 한 번 끊김 없이 진행한다.

```text
타이틀 → 프롤로그 → 주간 정비 → 야간근무 → 근무 결과 → 주간 정비
       → 둘째 야간근무 → 근무 결과 → 주간 정비 → 선택적 버전 업데이트
```

### 첫 실행과 오프닝

- 한글이 네모나 깨진 글자로 보이지 않는다.
- 메인 타이틀 `픽셀 야간근무`와 부제 `서버가 살아있다`가 겹치거나 잘리지 않는다.
- 프롤로그 첫 두 장 안에 `픽셀 야간근무`, 야간 관리자 역할과 `게임 서버 방어`가 쉬운
  말로 드러난다.
- 프롤로그는 `낡은 서버의 밤 → 쌓인 오류 → 자동 방어 → 낮의 정비 → 야간 인계`
  순서이고, 건너뛰기와 뒤로 가기가 정상 작동한다.
- 화면 문구와 그림이 특정 상용 IP 지식을 요구하지 않고 낡은 게임 서버·야간근무·직장
  코미디로 읽힌다.

### 주간 정비

- 기준 360×640에서 네 요원 요약과 선택 버튼을 화면 아래로 내리지 않고 볼 수 있다.
- 잠긴 요원, 패치와 슬롯에는 해금 조건과 현재 진행도가 보인다.
- 강화 비용, 현재 레벨과 강화 뒤 변화가 모두 정수로 표시된다.
- 패치를 바꾸기 전에 이점과 비용이 포함된 현재/변경 후 예측을 같은 화면에서 비교할 수
  있다.
- 오프라인 비트 안내는 주간에만 한 번 표시되고 같은 저장을 다시 열어도 중복 지급되지
  않는다.
- `다음 야간근무` 또는 `재도전`은 실제로 새 야간을 시작한다.
- 버전 업데이트는 둘째 야간 ★★★ 뒤 주간에서만 선택할 수 있고 자동으로 강요되지 않는다.

### 야간근무

- 무엇을 지키는지, 적이 서버에 닿으면 무엇이 줄어드는지 첫 화면에서 알 수 있다.
- 10칸 진행표와 3·6·10웨이브 별 경계, 다음 적을 구분할 수 있다.
- 일반 적 HP와 5초 제한시간, 보스 HP와 30초 제한시간이 서로 다른 위치·색·표기로
  보인다.
- 투사체 도착 또는 피격 효과와 HP 감소가 한 사건처럼 이어지고, 적이 사라진 뒤 늦게
  피해가 적용되지 않는다.
- 적 침입은 서버 안정도 감소와 즉시 연결되어 보인다.
- 요원 HP와 `쓰러짐`, QA 자동 구조를 별도 설명 없이도 상태 변화로 구분할 수 있다.
- 야간 설정을 열면 모달 위로 투사체·피해 숫자가 그려지지 않고 뒤의 전투 시간이
  진행되지 않는다.
- 해금된 재도전에서만 2배속을 고를 수 있고, 일반·보스 활성 시간만 빨라진다.

### 결과와 이어하기

- 성공·실패 직후 전투는 멈추고 결과가 정확히 한 번만 생성된다.
- 완료 웨이브, 별, 기본급·근무급·최초 별 보상과 총 비트가 구분된다.
- 실패 이유와 요원 보고가 실제 종료 원인과 맞고, 다음에 강화하거나 바꿀 항목을 찾을 수
  있다.
- 새 해금은 결과에서 최대 세 묶음으로 요약되고 다음 주간 화면에 반영된다.
- 결과에서 주간으로 돌아와도 보상이 다시 지급되지 않는다.
- 주간·야간·결과 각각에서 새로고침한 뒤 정확한 단계로 이어진다. 야간은 오프라인 전투를
  진행하지 않고 결과는 재정산하지 않는다.

## PC 웹 체크리스트

- Chrome 또는 Edge에서 세로형 게임 영역이 중앙에 있고 브라우저 폭을 바꿔도 360×640
  논리 화면이 찌그러지지 않는다.
- 마우스 클릭, 휠 스크롤과 키보드 포커스가 작동하며 툴팁이 화면 밖으로 잘리지 않는다.
- 탭을 다른 곳으로 옮겼다가 돌아와도 야간이 몰래 진행되거나 결과가 중복되지 않는다.
- 음악·효과음 슬라이더의 숫자, 손잡이 위치와 실제 음량이 0·50·100%에서 일치한다.
- 설정에는 실제 효과가 있는 항목만 보이며 `화면 흔들림` 행은 보이지 않는다.
- 설정과 확인창을 닫은 뒤 원래 Product V2 단계와 입력 상태로 돌아온다.

## Galaxy 웹 체크리스트

- 실제 Galaxy 기기에서 Chrome 주소창이 펼쳐지거나 접혀도 좌우 잘림과 과도한 빈 공간이
  없다.
- 짧은 360×640 비율과 긴 Galaxy 비율 모두에서 상단 노치·하단 제스처 영역이 핵심
  버튼을 가리지 않는다.
- 주요 버튼과 토글은 손가락으로 누르기 쉽고 최소 44×44 논리 픽셀의 터치 영역을 가진다.
- 네 요원 선택, 패치 탭, 설정 슬라이더와 결과 버튼이 서로 겹치지 않는다.
- 필요한 세로 스크롤은 자연스럽고, 내부 스크롤이 페이지 스크롤과 싸우거나 끝에서
  갇히지 않는다.
- 길게 누르지 않아도 자원·상태 설명 말풍선을 열고 다른 곳을 눌러 닫을 수 있다.
- 화면 회전, 앱 전환과 브라우저 복귀 뒤 저장이 깨지거나 보상이 중복되지 않는다.
- 첫 터치 뒤 소리가 재생되고 음소거·음량 변경이 실제 출력과 일치한다.

## 외부 5인 질문

진행자가 정답이나 개발 용어를 먼저 말하지 않는다. 각 참가자가 첫째 야간과 결과를 본
뒤 다음 다섯 질문에 자기 말로 답하게 한다.

1. 이 게임에서 당신은 누구이고, 밤마다 무엇을 지키나요?
2. 방금 야간근무는 왜 끝났나요? 적의 HP와 남은 시간은 화면에서 어떻게 달랐나요?
3. 다음 낮에는 무엇을 바꾸고 다시 출근하고 싶나요? 그렇게 고른 근거는 무엇인가요?
4. 고른 패치의 좋은 점과 감수할 점을 하나씩 말해 주세요. 버전 업데이트를 지금 하거나
   미룰 수 있다는 점도 이해됐나요?
5. 야간을 보는 동안 너무 빠르거나 지루하거나 `할 일이 없다`고 느낀 순간이 있었나요?

## 문제 기록

재현 가능한 문제에는 빌드 SHA, 기기, 단계, 기대 결과, 실제 결과와 스크린샷을 남긴다.
저장 손상·진행 막힘·보상 중복·전투 결과 불일치를 우선순위 높음으로 분류한다. 글자 잘림,
터치 불편과 설명 부족은 해당 F-ID와 연결해 다음 배포에서 재검증한다.
