# 회색 상자 플레이테스트

## 목적

콘텐츠 양이 아니라 `병목 관찰 -> 패치 선택 -> 전투 변화 -> 버전 업데이트`가
재미와 이해 가능한 선택을 만드는지 확인한다.

## 진행

1. 설명 없이 새 게임을 시작한다.
2. 관찰자는 조작 방법을 가르치지 않고 막히는 지점과 발화를 기록한다.
3. 참가자는 스테이지 20을 통과하거나 25분이 지나면 첫 회차를 종료한다.
4. 버전 업데이트가 열렸을 때 스스로 선택하는지 확인한다.
5. 업데이트를 선택했다면 두 번째 회차의 첫 보스까지 진행한다.

## 통과 기준

- 5명 중 4명이 병목 발생 후 10초 안에 원인을 설명한다.
- 5명 중 4명이 별도 설명 없이 진단 카드와 패치 화면을 찾는다.
- 5명 중 3명이 30초 안에 타당한 강화 또는 패치 변경을 수행한다.
- 5명 중 4명이 적용한 패치의 이점과 부작용을 설명한다.
- 패치 적용 후 3초 안에 전투 변화가 인지된다.
- 첫 보스는 평균 1~3회 실패 후 통과하고 누구도 5회 이상 막히지 않는다.
- 5명 중 4명이 첫 회차를 20분 안에 완료한다.
- 5명 중 3명이 강요 없이 버전 업데이트를 선택한다.
- 두 번째 회차의 첫 보스 도달 시간이 첫 회차보다 25% 이상 짧다.

## 실패 시 우선 수정

- 병목을 이해하지 못함: 콘텐츠를 추가하지 않고 진단 근거와 표현을 수정한다.
- 패치 차이를 느끼지 못함: 수치 차이와 화면 피드백을 강화한다.
- 항상 같은 패치가 정답임: 장점과 부작용 또는 보스 규칙을 다시 조정한다.
- 보스에서 장시간 정체됨: 유지보수 파밍과 교체 비용을 먼저 조정한다.
- 버전 업데이트를 피함: 초기화 항목, 유지 항목, 예상 단축 시간을 더 명확히 보여준다.

플레이테스트 로그에는 개인정보를 넣지 않으며, 전투 시도 단위의 집계만 기록한다.
