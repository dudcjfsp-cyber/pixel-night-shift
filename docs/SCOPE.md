# 20스테이지 회색 상자 범위

> 이 문서는 완료된 전투 회색 상자 마일스톤의 기준선입니다. 현재 확장 마일스톤은 [본편 혼합 전투 완성도 명세](COMBAT_HYBRID_SPEC.md)를 따릅니다. 앱 셸·저장·복귀 기준은 [앱 셸·야간 운영실 화면 명세](APP_SHELL_SPEC.md)에 유지됩니다. 아래의 제외 항목과 `main.tscn` 직접 시작 조건은 당시 범위를 기록한 것이며 새 마일스톤의 현재 규칙이 아닙니다.

## 목표

이번 단계의 목표는 콘텐츠 양이나 완성도를 늘리는 것이 아니라 다음 가설을 검증하는 것입니다.

> 완전 자동 전투에서도 플레이어가 병목을 읽고, 장단점이 있는 패치를 골라 결과를 비교하는 과정이 반복 탭보다 흥미로운가?

## 포함

- Godot 4.7, typed GDScript
- 논리 해상도 360×640의 세로형 화면
- 일반 적 3마리로 구성된 20스테이지
- 스테이지 10·20에서 강화 재사용되는 보스 1종
- 고정 요원 4명과 개별 레벨업
- 후보 패치 5개, 동시 장착 슬롯 3개
- 슬롯과 콘텐츠의 첫 회차 순차 해금
- 비트와 패치노트
- 스테이지 20 이후 자발적 버전 업데이트
- 패치노트로 구매하는 영구 보너스 1종·1레벨
- 보스 실패 후 자동 유지보수 파밍과 재도전
- 진단, 패치 미리보기, 오류 메시지를 포함한 회색 상자 UI
- 4요원·4적·보스·5패치·상태 아이콘과 서버실 배경의 재현 가능한 원본 픽셀 에셋
- 자동 전투·보스·유지보수 BGM과 진행·선택 피드백 효과음
- 전투 레인 시각화, 진단→패치 이동, 음악·효과음 토글을 포함한 1차 UI 개선
- 결정론, 성장 단조성, 패치 상충관계, 소프트락 방지, 버전 업데이트 보존 규칙, 콘텐츠 검증, 메인 장면 로드의 자동 테스트

## 이번 단계에서 제외

- 저장·불러오기와 저장 마이그레이션
- 오프라인 보상과 기기 시간 처리
- 부서 운영과 인력 배치
- 선택형 돌발 사건과 미니게임
- 장비, 인벤토리, 희귀도, 가챠, 요원 모집
- 두 번째 지역, 다중 전투 레인, 20 이후 스테이지
- 일일 퀘스트, 출석, 업적, 라이브 운영
- 광고, 결제, 분석, 계정, 서버, 네트워크 기능
- Android 내보내기·백그라운드 복귀·배터리 최적화
- 캐릭터 다중 프레임 애니메이션, 컷신, 보이스, 상용 음원, 진동
- 웹·iOS·다국어 정식 지원

제외 항목은 현재 코드에 빈 서비스, 가짜 버튼, 선행 데이터 구조로 미리 만들지 않습니다.

## 완료 조건

- 프로젝트가 `game/presentation/main.tscn`으로 바로 시작합니다.
- 전투와 보스 재도전에 반복 탭이나 수동 스킬이 필요하지 않습니다.
- 일반 적 체력과 요원 강화 비용이 단계에 따라 단조 증가합니다.
- 같은 초기 상태와 동일한 tick 입력은 같은 스냅숏을 만듭니다.
- 패치 미리보기에서 장점과 부작용이 모두 관찰됩니다.
- 보스 실패 후 유지보수 모드가 비트를 만들고 자동 재도전으로 돌아갑니다.
- 어떤 패치 구성에서도 첫 실패 무료 교체와 유지보수 파밍을 통한 복구 경로가 남습니다.
- 스테이지 20 클리어 후 버전 업데이트를 선택할 수 있습니다.
- 버전 업데이트가 회차 진행을 초기화하고 패치노트·발견·슬롯 해금을 보존합니다.
- 기본 콘텐츠 4요원·5패치가 로드되고 잘못된 콘텐츠 입력은 오류로 거부됩니다.
- 헤드리스 테스트와 메인 장면 실행에서 파서·누락 리소스 오류가 없습니다.

## 범위 변경 규칙

- 새 기능을 추가하려면 비슷한 구현·검증 비용의 기존 기능 하나를 빼거나 다음 단계로 명시적으로 이동합니다.
- 외부 의존성, 공개 API, 저장 스키마, 배포 대상, 데이터 마이그레이션은 별도 승인 없이 추가하지 않습니다.
- 핵심 순환 플레이테스트 전에는 현재 에셋 세트를 넘어 캐릭터·지역·음악 수를 확대하지 않습니다.

## 다음 단계 후보

핵심 순환이 검증된 뒤에만 다음 순서로 확장합니다.

1. 저장, 오프라인 진행, 손상 저장 복구
2. 30~50스테이지와 두 번째 보스
3. 오류 로그, 부서 1개, 사건 3개
4. 캐릭터 애니메이션과 두 번째 지역의 표현 확장
5. Android 입력·백그라운드·해상도 검증
