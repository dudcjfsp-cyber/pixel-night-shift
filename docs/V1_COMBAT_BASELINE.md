# 현재 본편 V1 전투 동결 기준선

## 문서 상태

- 상태: 읽기 전용 회귀 기준
- 동결 커밋: `4782087`
- 대상: Product V2가 6단계에서 승격되기 전의 현재 배포 본편
- 원본 상세 명세: `git show 4782087:docs/COMBAT_HYBRID_SPEC.md`

이 문서는 Product V2 목표 명세로 숫자를 치환하지 않는다. 2~5단계에서 격리된 Product V2
코드를 추가하는 동안 현재 배포 경로가 의도치 않게 바뀌지 않았는지 판정하는 기준이다.

## 전투 순환

| 항목 | 현재 V1 동작 |
|---|---|
| 진행 | 일반 적 3마리로 구성된 20스테이지 |
| 보스 | 스테이지 10·20의 `Watchdog Process` |
| 보스 제한시간 | 25초 |
| 일반전 | 요원 피해·DOWN·시간초과 없음 |
| 보스전 | 요원 역할·HP·DOWN·QA 구조 활성화 |
| 실패 | 유지보수 적 자동 파밍 뒤 같은 보스 자동 재도전 |
| 첫 보스 실패 | 무료 패치 교체 1회 |
| 회차 완료 | 스테이지 20 뒤 사용자가 버전 업데이트 선택 |
| 오프라인 | 현재 구성으로 같은 V1 전투 시뮬레이터를 최대 8시간 진행 |
| 저장 | schema 2, schema 1에서 원자적 전환 |

## 요원 기준

| 요원 | 기본 HP | 공격 주기 | 위협도 | 역할 보정 |
|---|---:|---:|---:|---|
| 디버거 | 200 | 1.0초 | 4 | 화력 ×0.50, 받는 피해 ×0.70 |
| 빌드 엔지니어 | 160 | 1.5초 | 2 | 받는 피해 ×0.85, 보스 피해 ×2.60 |
| 스프라이트 장인 | 125 | 0.75초 | 1 | 가동 중 팀 공격 주기 ×0.82 |
| QA 임프 | 140 | 1.2초 | 1 | 보스 시도당 자동 구조 1회 |

- 최대 HP 공식은 `기본 HP × 1.12^(레벨 - 1)`이다.
- 모든 요원은 기존 본편 DPS 성장 지수를 사용한다.
- 일반전에는 요원 HP와 DOWN을 표시하거나 계산하지 않는다.
- 보스 타깃 동률은 고정 ID 순서로 결정한다.

## 보스 행동 기준

| 행동 | 스테이지 10 | 스테이지 20 | 대상 |
|---|---:|---:|---|
| `POLL` | 2초마다 33 피해 | 2초마다 59.4 피해 | 위협도 1위 |
| `KILL SIGNAL` | 6초마다 66 피해 | 6초마다 118.8 피해 | 유효 DPS 1위 |
| `ROLLBACK` | 8초마다 최대 HP 12% | 6초마다 최대 HP 15% | 보스 |
| 처리량 저하 | 없음 | 전투 12초부터 팀 DPS ×0.80 | 가동 중 팀 |

같은 시각에는 `QA 구조 완료 → 요원 공격·보스 처치 → 보스 공격 → ROLLBACK → 시간초과`
순서로 처리한다. 정확히 25초의 처치는 성공이다.

QA 구조는 구조 지연 5초, 복귀 HP 40%, 보스 시도당 1회다. 완료 전에 QA 임프가 DOWN되면
예약을 취소한다.

## 패치와 성장 기준

- 기존 패치 후보 5개와 최대 장착 슬롯 3개를 사용한다.
- 패치 슬롯은 첫 회차 스테이지 3·11·15에서 열린다.
- 스프라이트 장인은 스테이지 3, QA 임프는 스테이지 6에서 열린다.
- 발견 요원·패치와 슬롯은 다음 회차에도 유지하고 요원 레벨·비트·장착 패치는 초기화한다.
- 스테이지 20 뒤 버전 업데이트를 실행하면 패치노트 1개를 받는다.

## 실패 복구와 보고서

- 보스 실패 뒤 유지보수 적을 자동 처리해 비트를 얻는다.
- 유지보수 중 요원 강화와 패치 변경을 허용한다.
- 정해진 유지보수 사이클 뒤 보스에 자동 재도전한다.
- 최신 실패 보고서는 보스 실패 사실에서 최대 2행을 만들고 읽기 전용 모달로 연다.
- 보고서 열람은 전투 명령, 보상 지급이나 숨은 효과를 만들지 않는다.
