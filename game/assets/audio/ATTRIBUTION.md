## Project-original audio

`bgm/maintenance_loop.wav` is deterministic procedural synthesis generated by `res://tools/generate_audio.gd`. It contains no recordings, samples, or external melodies.

The following effects are deterministic oscillator and seeded-noise synthesis generated by `res://tools/generate_original_sfx.py` using NumPy and Pedalboard:

- `sfx/combat_hit.wav`
- `sfx/enemy_break.wav`
- `sfx/operator_upgrade.wav`
- `sfx/boss_warning.wav`

These four effects contain no source audio or external samples. NumPy and Pedalboard are authoring tools only; the shipped game loads the final PCM WAV files without a Python runtime.
